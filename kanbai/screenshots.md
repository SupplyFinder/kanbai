# Screenshots: company specifics

Only used when `screenshots.enabled` is true in config.yml. `/kanbai setup` writes this file.

## Which repos
`web`.

## Real mode
How to log in with a test account (environment variable names, never the values), and how to reach a
preview of a PR (e.g. a preview deployment URL pattern) or run the branch locally.

## Stubbed mode
How to run the UI against a fake backend (test fixtures or a mock server), with obviously fictional data.

## Never in a screenshot
Real customer names, emails or data.
