# KanbAI company repo

This repo holds no product code. It is the company repo of KanbAI: every KanbAI session (orchestrator,
planning, coding, review) starts here to load the permission rules (`.claude/settings.json`), the skill
(`.claude/skills/kanbai/`) and the company settings (`kanbai/`).

Follow the `kanbai` skill (`/kanbai`). First time: run `/kanbai setup`.

Never write product code in this repo. Product work happens in the repos listed in `kanbai/repos.md`.
